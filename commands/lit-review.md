description: 从 S1 开始做一篇文献综述（选题 → 检索 → 初筛 → 精读 → 写作 → 统稿）
---

调用 `lit-review-6step` skill，入口固定为 **S1**。

1. 先复述用户给的主题，确认一句话范围（对象 / 材料 / 时间窗）。用户只给了一个词，就只问一个问题，不要一次问五个。
2. 按 S1 走：把“前人没做什么”拆成矛盾点、空白点、延伸点 → 收敛成一句 RQ → 3–5 个综述模块。
3. 产出 `00_选题/研究缺口与RQ.md` 并通过 S1 门禁后，才进 S2。

不要跳步，也不要在 S1 阶段就开始写正文或检索。
