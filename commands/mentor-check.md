name: mentor-check
description: 跑一次导师审查（MR），对照主题契约判断当前阶段有没有跑题
---

调用 `lit-review-6step` 的导师审查规则（`references/mentor-review.md`），只读、不改稿。

1. 读 `00_选题/主题契约.md`；没有就先让用户补，不要凭记忆审。
2. 读当前阶段的产物（候选表 / 提取表 / 提纲 / 正文 / 摘要）。
3. 只回答三个问题：还在回答同一个 RQ 吗？范围有没有扩大？有没有偷换成别的问题？
4. 每条结论给证据（哪一行、哪一段），判定 PASS / WARN / BLOCK。
5. WARN 或 BLOCK 写进 `00_选题/导师审查.md`；需要改契约时停下来问用户，不要自己改。

不评价学术质量，不审结构逻辑（那是 CR-S），不审语言（那是 HLA-S）。
