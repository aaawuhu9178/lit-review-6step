# 工作流说明

六步流水线的完整说明。技能内的 `references/pipeline.md` 是执行手册，本文是给人看的概览。

## 一句话

把文献综述拆成六个可验收的阶段，每阶段一个产物、一道门禁；成稿按「新技术 × 旧问题」的七节骨架写。

## 六步

| 阶段 | 做什么 | 产物 | 门禁 |
|---|---|---|---|
| S1 选题 | 把"前人没做什么"拆成矛盾点 / 空白点 / 延伸点，收敛成一句 RQ | 缺口陈述 + RQ + 3–5 模块 | 第三人能复述 RQ |
| S2 策略 | PICO/SPIDER 拆概念块 → 选库 → 分库写检索式 | 检索策略表 + 检索日志 | 每行有库 / 式 / 限定 / 预计量 |
| S3 检索初筛 | 多通道检索 → 去重 → 按排除码初筛 → 算 PRISMA | 候选表 + 筛选记录 | 计数闭合，每条有排除码 |
| S4 精读提取 | Keshav 三遍法读，结构化入表 | 提取表 + 笔记 | 纳入文献 100% 有行，局限非空 |
| S5 综合写作 | 概念矩阵 → 主题分组 → 冲突地图 → 提纲 → 逐章写 | 概念矩阵 + 冲突地图 + 提纲 + 初稿 | taxonomy 过十篇盲测，每段 ≥2 篇对撞 |
| S6 统稿 | 逻辑、过渡、术语、格式、引用核查、摘要 | 终稿 + 摘要 + 自检清单 | 引用可回溯，摘要承诺兑现 |

## 入口

不必从 S1 开始。按手上材料选择入口，跳过的阶段登记为"欠账"，在后续阶段补：

| 入口 | 手上有什么 | 跳过 | 欠账 |
|---|---|---|---|
| S1 | 只有方向 | — | — |
| S2 | 已定题目（±RQ、±范围） | S1 | 引言"现有综述总结"（S5 补） |
| S3 | 检索式 / 策略表 | S1–S2 | 方法节检索协议（S6 补） |
| S4 | 筛选后的文献清单 | S1–S3 | PRISMA 计数（S6 补） |
| S5 | 提取表 | S1–S4 | 引用可回溯性（S6 核） |
| S6 | 已有初稿 | S1–S5 | 先结构诊断再润色 |

三条跳步规则：最小输入必须齐；欠账写进 `00_选题/研究缺口与RQ.md` 顶部；候选表始终是唯一事实源。

## 结构模式一

```text
1 引言
2 背景知识
  2.1 问题背景（分类 A：a1…am）
  2.2 新技术背景（分类 B：b1…bk，末尾声明映射到第 3 章起）
3 新技术 b1 背景下的问题 a1
4 新技术 b2 背景下的问题 a2
5 新技术 b3 背景下的问题 a3
6 研究挑战与未来方向
7 结论
```

硬约束：B 的类数 = 第 3 章起的章数；B×A 交叉矩阵动笔前填满；|A| ≠ |B| 时按 B 分章并说明映射。

## 三条硬规则

1. 候选表是唯一事实源，表外文献不进提取和写作。
2. 每次检索留痕：日期 / 通道 / 检索式 / 命中 / 保留。
3. 门禁不过就停，不靠后面的写作补前面的洞。

## 失败处理

| 故障 | 处理 |
|---|---|
| 检索通道不可用 | 手工检索，结果按候选表字段录入，`channel` 标 `wos`/`cnki`/`gs` |
| 拿不到 PDF | 走"文献获取"流程；仍拿不到就只做摘要级提取并注明 |
| 筛不动 | 课程综述用轻量筛选 + 10% 复核；系统综述用双盲 + 第三仲裁 |
| 没有关系图工具 | 用概念矩阵的行列关系代替 |
