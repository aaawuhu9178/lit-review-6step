# 六阶段执行手册

每阶段开始先读对应子 skill 的 `SKILL.md`（路径见主文件依赖表），按它的工作流做，不凭记忆。每阶段结束把产物写进项目目录，再对照门禁自检。

---

## 入口契约（从 S2–S6 进）

从中间进入时，先校验"最小输入"，再登记"欠账"。缺项不要硬跑。

### S2（已有题目）

- **必须**：题目一句话；范围（学科 / 时间窗 / 语言，缺省可由 AI 提议并标注为假设）。
- **可选**：RQ、已有 5–10 篇文献。
- **动作**：写 RQ 卡（题目 / 一句 RQ / 概念块）→ 拆 PICO/SPIDER → 选库 → 出策略表。
- **校验**：RQ 含对象、机制、边界；概念块 ≥2；策略表 ≥3 行，每行有库和检索式。
- **欠账**：`入口=S2；欠账=缺口论证`。

### S3（已有检索式或指定库）

- **必须**：检索式清单，或"库 + 关键词 + 限定"。
- **动作**：先落策略表（哪怕 3 行），再执行、去重、初筛。
- **校验**：每行有库 / 式 / 限定；日志有检索日期。
- **欠账**：`入口=S3；欠账=检索策略的完整性`。

### S4（已有文献清单）

- **必须**：清单含标题、年份、来源（期刊 / 会议 / 预印本），并已标明纳入。
- **动作**：重建候选表——逐条分配 id、`channel=user`、`included=1`、`note=用户提供`；缺 DOI 的留空并在 note 标注；再进精读。
- **校验**：清单条数 = 候选表行数；id 唯一。
- **欠账**：`入口=S4；欠账=PRISMA 计数与筛选透明度`。

### S5（已有提取表）

- **必须**：提取表含 id 与至少 title / year / venue。
- **动作**：按 id 反推候选表（`channel=user`、`included=1`）；提取表缺的题录从候选表补。
- **校验**：提取表 id 唯一；候选表覆盖全部 id。
- **欠账**：`入口=S5；欠账=筛选与检索记录`。

### S6（已有初稿）

- **必须**：初稿全文。
- **动作**：先抽引用建候选表（`channel=draft`、`included=1`）；再按 `survey-writing` §7 做结构诊断；最后才润色。
- **校验**：每条引用能在候选表找到，找不到标"待核"。
- **欠账**：`入口=S6；欠账=检索、筛选、提取链`。

### 欠账登记格式

写进 `00_选题/研究缺口与RQ.md` 顶部：

```text
入口：S2（用户已定题目）
跳过：S1 缺口分析
欠账：引言"现有综述总结"段（S5 补） / 方法节检索协议（S6 补）
```

## 每阶段结束：导师审查

进下一阶段前先跑 **MR**（规则见 `references/mentor-review.md`）：对照 `00_选题/主题契约.md`，只判断"还在回答同一个问题吗"。PASS 后再看本文件对应阶段的门禁。

| 阶段 | MR 只查 |
|---|---|
| S1 | 缺口是否支撑 RQ、模块是否都在范围内 |
| S2 | 概念块是否覆盖对象/机制/边界，有没有范围外概念 |
| S3 | 纳入文献是否服务 RQ，E1 是否被滥用 |
| S4 | relevance 能否指回章节 |
| S5 | taxonomy 是否回答 RQ、章节是否一一对应、有没有新增问题 |
| S6 | 终稿与摘要是否回答 RQ、结论是否超出证据 |

WARN 记录进 `00_选题/导师审查.md`；BLOCK 退回上一阶段，不靠写作补。

## S1 选题：从研究不足到研究问题

**读**：`literature-review-skills/skills/refine-literature-question/SKILL.md`、`.../locate-review-research-gap/SKILL.md`

**输入**：一个宽泛主题；已有的阅读/笔记（可为空）。

**动作**：把"前人没做什么"拆成三类，不要混着写——

| 类型 | 判据 | 例子 |
|---|---|---|
| 矛盾点 | 同一问题，结论相反或方向不一致 | A 说提升收益，B 说只对头部有效 |
| 空白点 | 该情境/人群/变量组合无人研究 | 都研究城市，没人研究县域 |
| 延伸点 | 结论成立但边界未测 | 只测短期，长期未知 |

**产物** `00_选题/研究缺口与RQ.md`：缺口陈述（≤200 字，每条断言标依据）→ RQ 一句话（对象 + 机制 + 边界）→ 3–5 个综述模块 → 可行性（可得文献量、数据可得性）。

**门禁**：没参与的人读完 RQ，能说出"你打算搜什么、不搜什么"；缺口陈述的每条断言都有出处或明确标注"待检索验证"。

## S2 策略：项目初始化与检索策略

**读**：`literature-review-skill/skills/文献检索/SKILL.md`

**动作**：
1. 先定综述类型（叙事 / 系统 / 范围 / 快速 / 引言 mini），它决定检索严格度与 PRISMA-S 要求。
2. 按 PICO / PICOC / SPIDER 拆概念块，每块 3–8 个同义词，中英各一列；查 MeSH/主题词。
3. 选库：系统综述至少 4 英 2 中；课程综述至少 2 英 1 中。
4. 写检索式：**一个库一行**，语法不能跨库复制（WoS `TS=`、PubMed `[Title/Abstract]`、Scopus `TITLE-ABS-KEY`、CNKI `SU=`）。
5. AMiner 通道：按 `references/aminer.md` 把概念块组合成 AMiner 查询，先跑健康检查。

**产物** `01_检索/检索策略表.md`、`01_检索/检索日志.md`（先建表头）。

**门禁**：每行都有库 / 检索式 / 限定 / 预计命中；总量与目标篇数匹配（课程 20–40，学位 60–120，系统综述数百）。

## S3 检索与初筛

**通道**：AMiner（机器可查）+ WoS/CNKI/Google Scholar（手工，按同一字段录入）。

**执行**：
1. AMiner：每个查询取 2–3 页（10 条/页），`order=n_citation` 取奠基文献，`order=year` 取前沿；期刊定向用 `search_papers_by_venue`，核心作者用 `search_papers_by_author`。
2. 每条结果写入 `01_检索/候选表.csv`，`channel=aminer`，`query` 填实际关键词。
3. 去重：DOI 优先；无 DOI 时标题归一化（小写、去标点、去空格）比对。
4. 初筛：逐条读 title + abstract，给 `included`（0/1）+ `exclude_code` + `note`。
5. 排除码固定七类（见 `02_筛选/排除原因码.md`），不许自由发挥。
6. 统计 PRISMA 计数：检索命中 → 去重后 → 题摘排除 → 全文评估 → 最终纳入。

**产物** `01_检索/候选表.csv`、`02_筛选/筛选记录.md`。

**门禁**：每条 included=0 都有排除码；PRISMA 计数闭合（命中 − 重复 − 排除 = 纳入）；系统综述走 `sr-screener` 的双盲 + 第三仲裁，叙事/课程综述用轻量筛选并抽 10% 复核。

## S4 精读与提取

**读**：`literature-review-skill/skills/文献精读/SKILL.md`

**动作**：Keshav 三遍法——第一遍 10 分钟判断值不值得读；第二遍抓论证结构与证据链；第三遍复现关键细节。笔记落 `03_精读/notes/`，结构化字段落 `03_精读/提取表.csv`。

**字段**：研究目的 / 方法 / 样本或数据 / 关键发现 / 局限 / 与我的 RQ 的关系 / 可引用原句 + 页码。

**门禁**：候选表 `included=1` 的每一篇都有提取行；"局限"列为空的行退回重读，不许留白。

## S5 综合写作

**读**：`literature-review-skill/skills/文献综述写作/SKILL.md` + `literature-review-skills/skills/map-literature-contradictions/SKILL.md`

**动作**：
1. 概念矩阵：行 = 纳入文献，列 = 概念（不是作者）。
2. 列聚成 3–7 个主题；每组写"一致在哪 / 分歧为何 / 适用边界 / 方法演变"。
3. 冲突地图：把结论相反的组单列，标差异来源（样本、测量、情境、时间）。
4. 逐段写作：每段先给判断，再给证据；结尾 gap 段逐条挂回 RQ。
5. **出图**：提纲里的图表计划逐张交给 `nature-figure`（读 `.dsh/skills/nature-figure/SKILL.md`）：
   - 数据图 / 对比图 → Python 或 R 绘图后端（matplotlib / ggplot2），输出矢量 PDF + SVG；
   - 结构图 / taxonomy 总图 / 框架图 → 矢量示意图路线（SVG），或 Mermaid 生成骨架再精修；
   - 交付前跑它自带的 `scripts/audit_svg_schematic.py` 或 `scripts/validate_figure.py`；
   - 命名与存放：`04_综合/figures/Fig1_xxx.pdf|.svg|.png`，与提纲编号一一对应。

**门禁**：每段至少 2 篇文献对撞；没有"作者 A 说…作者 B 说…"的流水账；每个 gap 能指到 RQ 的哪一句；图表计划里的每张图要么已出图、要么明确标"不画"并说明理由。

## S6 统稿与格式

**读**：`literature-review-skill/skills/文献综述章节/SKILL.md`；引用核查调 `academic-paper` 的 citation-check 模式。

**动作**：逻辑链（问题 → 已知 → 争议 → 缺口 → RQ）→ 过渡句 → 术语与时态统一 → 格式统一（GB/T 7714 或 APA，全文一种）→ 引文与参考文献一一对应。

**门禁**：Boote & Beile 12 条打分（博士 ≥18/24，硕士 ≥15/24）；随机抽 10 条引用回原文核对，错 1 条就全表复查。

## 常见失败模式

| 症状 | 根因 | 处理 |
|---|---|---|
| 综述写成读书笔记 | S5 按作者组织 | 回 S5 重排概念矩阵 |
| 检索"搜不全" | S2 概念块同义词不足 / 只搜一个库 | 回 S2 补同义词和库 |
| 筛到一半筛不下去 | 排除码不固定，标准漂移 | 回 S3 先定码再筛 |
| 写作时发现关键文献没读 | 候选表外引用 | 停写，回 S3 补录并重跑门禁 |
| 引用对不上 | 提取表没存页码 | 回 S4 补 quote + page |
