# 综述结构模式

写作阶段（S5/S6）先选结构模式，再动笔。结构模式决定章节骨架；`survey-writing` 决定每个格子怎么写。

- 模式一：**新技术 × 旧问题**（进展型）——本文采用的结构，见下。
- 其他模式：待补，收到后按同一格式追加。

---

## 模式一：新技术在旧问题上的进展

**适用**：一个成熟领域（旧问题 A）遇到一类新技术（B），交叉地带的文献在近几年爆发，但现有综述要么只讲技术、要么只讲问题。

**物种**：问题导向型（`survey-writing` §1）。主线是领域自身的问题结构，不是技术编年史。

**一句话论点模板**：

> 现有工作可以沿 B 的技术分支组织；沿 A 的问题分支看，b_i 主要解决了 a_i，真正的空白是 ___，因为 ___。

### 章节骨架

| 章 | 标题 | 写什么 | 从哪来 |
|---|---|---|---|
| 1 | 引言 | 领域大背景 → 小背景（旧问题遇到新技术）→ **现有综述总结**（either/or 缺口句）→ 本综述特点（3–5 条贡献）→ 论文结构 | `survey-writing` §4.2 六段漏斗（可选加"挑战 (i)(ii)(iii)"段，作为 2.2 的引子） |
| 2 | 背景知识 | 两个 taxonomy 的地基 | — |
| 2.1 | 问题背景 | 旧问题 A 的通用描述（是什么）→ 细化分类 A：a1…am（有哪些种类） | 第 1 步的 RQ + 缺口 |
| 2.2 | 新技术背景 | 新技术 B 的通用描述 → 分类 B：b1…bk → **末尾一句映射声明**：b1→第 3 章，b2→第 4 章… | 第 2–4 步的文献 |
| 3 | 新技术 b1 背景下的问题 a1 | b1 的定义与边界 → 它切中 a1 的哪一面 → 代表工作演进 → 对比表 → 未解决什么 | 交叉矩阵第 1 行 |
| 4 | 新技术 b2 背景下的问题 a2 | 同上，换 b2 / a2 | 交叉矩阵第 2 行 |
| 5 | 新技术 b3 背景下的问题 a3 | 同上，换 b3 / a3 | 交叉矩阵第 3 行 |
| 6 | 研究挑战与未来方向 | 每个挑战 = 陈述 + 为何难 + 现有为何不够 + 突破口 + 验证方式；方向与挑战一一对应 | 第 3–5 章的小结 |
| 7 | 结论 | 回收两个 taxonomy 与交叉映射（不引新文献）→ 领域愿景 | `survey-writing` §4.4 |

### 两个 taxonomy 的硬要求

**A（旧问题）**：3–5 类，互斥、穷尽、稳定；每类给判据（什么算 / 什么不算）和代表工作。分类轴来自领域自身，不要为分类而分类。

**B（新技术）**：3–5 类，**必须与第 3 章起的章节一一对应**。B 多一类就多一章，少一类就并一章——不要在 2.2 写四类、正文只写三章。

**A 与 B 的配对**：
- 默认配对：b_i 对 a_i（模式一的标准形态）。
- 若 |A| ≠ |B|：按 B 分章，每章内部覆盖与 b_i 相关的 A 子集，并在 2.2 末尾写明"本章覆盖 a1、a3，a2 见第 5 章"。
- 不允许：一章里塞两个互不相关的 b，或某章没有明确的 a。

### 交叉矩阵（动笔前必须填）

行 = B 的技术分支，列 = A 的问题分支，格子 = 文献数 / 代表作。

| | a1 | a2 | a3 |
|---|---|---|---|
| b1 |  |  |  |
| b2 |  |  |  |
| b3 |  |  |  |

- 每个 **行** 至少有一个非空格，否则该 b 不该单独成章。
- 每个 **列** 至少有一个非空格，否则该 a 在本文中没有被覆盖，要在 1 章的范围声明里说明。
- **空格**是未来方向的候选，但先验证是真空白（换关键词、换库再搜一次），别把"我没搜到"写成"没人做"。
- 对角线（b_i × a_i）是第 3–5 章的主干；非对角线的密集格，在第 6 章作为"跨分支组合"的挑战提出。

### 每章（3–5）的五段模板

1. **定义与边界**：b_i 是什么、不是什么（承 2.2）。
2. **对应问题面**：b_i 切中 a_i 的哪一面，为什么是这一面（承 2.1）。
3. **代表工作演进**：按时间或思想线索，不按作者排队；每篇给"解决了什么"。
4. **对比表**：方法 × 关键机制 × 数据 × 指标 × 局限，全表统一记号。
5. **未解决**：3 条以内，每条要能进第 6 章。

### 门禁

| 门 | 检查 | 不过怎么办 |
|---|---|---|
| G-A | A、B 两个 taxonomy 各自通过十篇盲测（≥8/10 稳定落位） | 回 2.1 / 2.2 重划 |
| G-B | 交叉矩阵无未解释的空行/空列；对角线有文献 | 回检索补，或改章节映射 |
| G-C | 第 6 章每个挑战都能指回第 3–5 章某一节的小结 | 回 3–5 补"未解决" |
| G-D | 1 章的"现有综述总结"至少点名 3 篇同类综述，并说清 either/or | 回 S3 补综述类文献 |

### 与通用五节骨架的关系

`survey-writing` 的五节骨架（引言 / 预备 / 主体分类 / 应用 / 挑战）是通用型；模式一是它在"旧问题 × 新技术"场景下的具体化：

- 预备知识 → 第 2 章（拆成 2.1 / 2.2 两个 taxonomy）
- 主体分类 → 第 3–5 章（按 B 分章，章内按 A 定位）
- 应用 → 并入第 3–5 章的"代表工作"与第 6 章，不单独成章（除非应用本身是分类轴）
- 挑战与展望 → 第 6 章
- 结论 → 第 7 章

所以 `survey-writing` 的 Gate A/B/C 仍然全部适用，只是章节名换成了模式一的七节。
