## 自检

- [ ] 钩子不是领域重要性套话
- [ ] 缺口句用 `However`，且具体
- [ ] 有明确的综述定位句
- [ ] 框架有分类轴，不是 A/B/C 罗列
- [ ] 提出 taxonomy 时摘要明写
- [ ] 数字可核验，资源链接可访问
- [ ] 没有误用 `novel`
- [ ] 结尾成对写挑战与机会
- [ ] 摘要板块与正文一一对应
