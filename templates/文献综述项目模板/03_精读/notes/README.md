# 精读笔记

每篇一个文件：`<id>-<第一作者>-<年份>.md`。模板：

```markdown
# <标题>

- id: AM-0001
- 年份 / 期刊：
- DOI：
- 读了几遍：
- 结论：值得精读 / 只需摘要

## 第二遍：论证结构

- 研究目的：
- 方法：
- 样本 / 数据：
- 核心论点链：

## 第三遍：细节与可信度

- 关键数字：
- 对照 / 基线：
- 局限（作者承认 + 我发现的）：

## 与我的 RQ

- 支持 / 反对 / 无关：
- 可引用原句（页码）：

## 待核

-
```

结构化字段同步进 `../提取表.csv`，笔记负责"为什么"，CSV 负责"是什么"。
