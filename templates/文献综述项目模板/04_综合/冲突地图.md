# 冲突地图

把"结论相反"的组单列出来，重点不是谁对，而是**为什么不同**。

| # | 议题 | 结论 A（文献） | 结论 B（文献） | 差异来源 | 我的判断 |
|---|---|---|---|---|---|
| 1 |  |  |  | 样本 / 测量 / 情境 / 时间 / 方法 |  |

## 差异来源清单

| 来源 | 问法 |
|---|---|
| 样本 | 人群、行业、国家、规模是否可比 |
| 测量 | 同一构念是否用了不同量表/代理变量 |
| 情境 | 制度、市场阶段、平台规则差异 |
| 时间 | 短期 vs 长期，疫情前后 |
| 方法 | 因果识别策略、模型设定 |

## 输出

每个冲突组写一句"综合判断"：目前能说到什么程度，还差什么证据。这句话可以直接进 S5 的正文。
