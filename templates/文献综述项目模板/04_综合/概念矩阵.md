# 概念矩阵

行 = 纳入文献（只放 `included=1`），列 = 概念（**不是作者**）。格子填"该文对这个概念说了什么"，用 3–10 个字，不写整句。

| 文献 | 概念 1 | 概念 2 | 概念 3 | 概念 4 | 方法 | 样本/情境 |
|---|---|---|---|---|---|---|
| AM-0001 |  |  |  |  |  |  |
|  |  |  |  |  |  |  |

## 聚组

把列聚成 3–7 个主题，写清每组覆盖哪些列：

| 主题 | 包含概念 | 文献数 | 一句话判断 |
|---|---|---|---|
|  |  |  |  |

## 自检

- [ ] 没有按作者分组
- [ ] 每个主题至少 2 篇文献
- [ ] 空格子有解释（该文确实没谈，还是我没读到）
