# 文献综述项目模板

## 用法

整份复制，改名 `综述_<主题>_<YYYYMMDD>/`，然后按六步推进。入口是 `.dsh/skills/lit-review-6step/SKILL.md`。

可以从任一步进入：已有题目从 S2、已有检索式从 S3、已有文献清单从 S4、已有提取表从 S5、已有初稿从 S6。跳步前先看 `.dsh/skills/lit-review-6step/references/pipeline.md` 的「入口契约」，并在 `00_选题/研究缺口与RQ.md` 顶部登记欠账。

## 六步与产物

| 步 | 阶段 | 产物 | 门禁 |
|---|---|---|---|
| S1 | 选题 | `00_选题/研究缺口与RQ.md` | RQ 一句话 + 3–5 模块 |
| S2 | 策略 | `01_检索/检索策略表.md` | 每行有库/检索式/预计量 |
| S3 | 检索初筛 | `01_检索/候选表.csv`、`02_筛选/筛选记录.md` | 每条有排除码，PRISMA 闭合 |
| S4 | 精读提取 | `03_精读/提取表.csv`、`03_精读/notes/` | 纳入文献 100% 有提取行 |
| S5 | 综合写作 | `04_综合/概念矩阵.md`、`04_综合/冲突地图.md`、`05_成稿/提纲.md`、`05_成稿/初稿.md` | 先定结构模式；taxonomy 过十篇盲测；每段 ≥2 篇对撞 |
| S6 | 统稿格式 | `05_成稿/终稿.md`（另存）、`05_成稿/摘要.md`、`05_成稿/自检清单.md` | 引用可回溯 + 格式统一 + 摘要承诺兑现 |

## 三条硬规则

1. `01_检索/候选表.csv` 是唯一事实源：后面只能引用 `included=1` 的行。
2. 每次检索都在 `01_检索/检索日志.md` 留一行。
3. 门禁不过就停，不要靠润色补前面的洞。

## 模板来源

表格模板的权威版本在 `.dsh/skills/lit-review-6step/assets/`；这里是从中复制的一份，改字段时两边同步。
